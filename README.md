# 🗺️ Roadmap Platform

Платформа для создания, прохождения и публикации интерактивных образовательных дорожных карт (роадмапов). Позволяет проектировать визуальные траектории обучения, отслеживать прогресс, прикреплять учебные материалы и изучать готовые роадмапы из каталога.

Модульный монолит на **Spring Boot 4** на бэкенде и **React + TypeScript + Vite** на фронтенде.

---

## Основные возможности

- **Интерактивный конструктор и просмотрщик:** холст для управления узлами, связями, секциями и текстыми блоками.
- **Каталог дорожных карт:** поиск, фильтрация по категориям и тегам, публичные и приватные роадмапы.
- **Отслеживание прогресса:** запись на дорожные карты, чек-листы и статусы прохождения тем.
- **Отзывы и рейтинги:** оценивание и комментирование роадмапов.
- **Профиль и авторизация:** регистрация, JWT-авторизация (с refresh token), управление личными роадмапами и настройками.

---

## Стек технологий

### Backend
- **Язык и среда:** Java 21 
- **Фреймворк:** Spring Boot 4.1.1 (Spring Web, Spring Security, Spring Data JPA)
- **База данных:** PostgreSQL 16
- **Миграции:** Flyway
- **Аутентификация:** JJWT (JWT Access + Refresh tokens)
- **Документация API:** OpenAPI 3 / Swagger (`springdoc-openapi`)
- **Маппинг и утилиты:** MapStruct, Lombok
- **Тестирование:** JUnit 5, Mockito

### Frontend
- **Фреймворк:** React 19, TypeScript 5.9
- **Сборщик:** Vite 8
- **Маршрутизация:** React Router 8
- **Управление состоянием:** TanStack Query 5, Zustand 5 
- **Стилизация:** Tailwind CSS 4
- **Тестирование и линтинг:** Vitest, Testing Library, ESLint, Prettier

### Инфраструктура
- **Контейнеризация:** Docker, Docker Compose
- **Web-сервер:** Nginx (на фронтенде)

## Запуск проекта

1. **Создайте файл окружения:**
   ```bash
   cp .env.example .env
   ```
   (Возможно редактирование портов и паролей в `.env`)

2. **Запустите контейнеры:**
   ```bash
   docker compose up --build
   ```
